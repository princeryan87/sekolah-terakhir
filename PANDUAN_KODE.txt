PANDUAN KODE: THE LAST (Godot 4.3, Compatibility, semua objek dibuat lewat kode)
=================================================================================
Tempel file ini ke chat baru agar Claude tidak perlu membaca semua kode lama.

ATURAN UPDATE
- Tiap misi baru = 1 zip berisi HANYA file baru/berubah. Ekstrak, lalu unggah ke repo
  yang sama dalam SATU commit (file bernama sama otomatis tertimpa, build berjalan sekali).
- File inti jarang diubah. Jika diubah, zip memuat file itu UTUH.
- Daftar suara baru tiap misi: audio/list_misi_NN.txt (hanya nama yang belum pernah ada).
- package/unique_name TIDAK BOLEH diubah. debug.keystore TIDAK BOLEH diganti
  (agar APK baru bisa menimpa APK lama dan simpanan tidak hilang).
- GDScript: indentasi 4 spasi, tanpa karakter non-ASCII, tanpa class_name,
  tanpa "for a, b in dict", hindari ":=" untuk nilai Variant.

KERANGKA MISI (scripts/misi/misi_NN.gd), menu membaca JUDUL dan RINGKAS otomatis
  extends Node
  const JUDUL = "..."
  const RINGKAS = "..."
  var main        # diisi oleh main.gd sebelum jalankan()
  func jalankan(lanjut: bool):          # coroutine; lanjut = lanjut dari checkpoint
      var hud = main.hud
      hud.hitamkan()
      var dunia = main.buat_dunia(preload("res://scripts/lantai1.gd"))   # lantai apa pun
      var pemain = main.pemain
      dunia.hook_aksi = Callable(self, "_aksi")   # _aksi(id, node) -> bool (true = sudah ditangani)
      ... atur cerita ...
  Selesai: GameState.tandai_selesai(NN); layar akhir; main.kembali_ke_menu()
  Checkpoint: GameState.set_cp(NN, "nama") dan GameState.ambil_cp(NN) ("awal" = tidak ada)
  Isi dunia.selesai = true saat misi selesai (mencegah tertangkap).

RENCANA MISI
  [SELESAI DIBUAT: misi 1..10 = SEASON 1 TAMAT]
  1 Hukuman Bersih-Bersih (Kuntilanak)   2 Sang Guru (kejar+sembunyi)   3 Lantai Atas (Genderuwo, sekering)
  4 Perpustakaan (hantu siswi, kode)     5 Lorong Pocong (hanya bergerak saat tak disorot, 3 kunci)
  6 Ruang Guru (Tuyul mencuri barang)    7 Toilet (baterai senter terbatas, Kuntilanak agresif)
  8 Lapangan dan Gudang (Genderuwo+Pocong, berkabut)   9 Kelas 9-X (kebenaran, semua hantu bergantian)
  10 Ruang Kepala Sekolah (boss, penguasa kerajaan hantu; ending baik/buruk/rahasia)
  Tiap misi makin sulit: kec_kejar naik, hantu bertambah, tempat sembunyi dan baterai berkurang.

ALUR CERITA SEJAK MISI 8 (untuk Misi 10 / boss)
  Kelas 9-X membuktikan: para murid dijadikan penjaga oleh Kepala Sekolah (Sari=Kuntilanak, Pak Mandor=Genderuwo,
  Pak Darto=Pocong, Dina=hantu siswi, Bu Wali=Sang Guru). Raka murid terakhir yang namanya tidak pernah dihapus.
  Dari Kelas 9-X ada pintu_kepsek ke lorong merah menuju ruang Kepala Sekolah (boss, penguasa kerajaan hantu).
  Dokumen total 16 (dok_1..dok_16); ending rahasia bila semua dokumen terkumpul. Buku Besar disebut di dok_5, dok_10, dok_11.

AKHIR SEASON 1 DAN RENCANA SEASON 2
  Ending Season 1: Raka keluar dari gerbang sekolah; jam di tangannya masih 00:00; jalan pulang gelap dan tak dikenal.
  Season 2 (rencana, belum dibuat): misi baru DI LUAR sekolah, perjalanan pulang ke rumah di malam hari.
  Bila dibuat: perluas GameState.JUMLAH_MISI (menu otomatis menampilkan lebih banyak kartu; atur tata letak menu.gd),
  atau buat file misi_11.gd dst. Menu hanya membaca scripts/misi/misi_NN.gd untuk NN <= JUMLAH_MISI.
